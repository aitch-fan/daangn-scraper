당근마켓 아이폰 중고 매물 분석 및 자동 수집기 (Daangn iPhone Scraper)

당근마켓의 중고 아이폰 판매 게시글(제목, 가격, 본문 텍스트 및 실물 사진)을 Playwright로 크롤링 -> Google Gemini AI를 통해 상태를 분석 -> 정형화된 텍스트로 output 출력 -> CSV 파일로 누적 저장

`실행.bat` 더블 클릭 한 번으로 간편하게 사용할 수 있도록 제작되었습니다.

---

## ✨ 주요 기능

- **⚡ 원클릭 자동 실행 지원 (`실행.bat`)**
  - 가상환경 구축, 패키지 설치, 스크래핑용 크로미움 브라우저 설치까지 모두 자동으로 진행되어 더블 클릭만으로 바로 사용할 수 있습니다.
- **🔍 멀티모달 AI 정밀 분석 (Google Gemini 3 Flash / 3.8 Flash)**
  - 본문 설명뿐만 아니라 **실제 첨부된 실물 사진(최대 3장)**을 AI가 직접 판독하여 파손 여부와 상세 상태를 분석합니다.
  - 일시적 서버 부하(503 트래픽) 발생 시 자동으로 대기 후 재시도하며, 안정적인 모델 풀로 자동 폴백(Fallback)합니다.
- **📊 데이터 규격 정규화 및 수치화**
  - 분석된 데이터를 엑셀에서 가공 및 머신러닝에 바로 활용할 수 있도록 일관된 규격(숫자, 코드)으로 정제합니다.
  - 유효한 데이터 분석에 실패한 경우 불필요한 빈 행이 저장되지 않도록 방어합니다.
- **🔄 지속 대화형 입력 루프 (Interactive Loop)**
  - 프로그램을 껐다 켤 필요 없이, URL을 연속으로 붙여넣으며 계속해서 CSV에 누적할 수 있습니다. (`c` 입력 시 종료)
- **🔒 API 키 분리 및 안전한 보안 (`api_key.txt`)**
  - 소스코드에 API 키를 노출하지 않고 `api_key.txt`로 분리 관리하며, `.gitignore`에 등록되어 깃허브에 절대 유출되지 않습니다.
  - 최초 실행 시 콘솔에서 키를 한 번만 입력하면 자동으로 저장되어 다음부터는 묻지 않습니다.

## 📋 CSV 데이터 추출 규격 (`daangn_items.csv`)

분석된 데이터는 Excel에서 한글 깨짐이 없는 `utf-8-sig` 인코딩 형식으로 저장됩니다.

| 컬럼명 | 데이터 예시 | 설명 |
| :--- | :--- | :--- |
| **모델** | `15`, `16`, `15p`, `16p` | 아이폰 15, 16, 15 프로, 16 프로 4종 규격화 |
| **가격** | `1000000`, `500000` | '원' 및 쉼표(`,`)를 제외한 순수 숫자 |
| **용량** | `128`, `256`, `512` | 'GB'를 제외한 순수 숫자 |
| **배터리효율** | `100`, `85` | 퍼센트(`%`)를 제외한 최대 효율 수치 |
| **전면액정** | `0` ~ `3` | 전면 액정 파손 상태 (0: 무하자 / 1: 미세기스 / 2: 깨짐·줄감 / 3: 사용불가) |
| **후면액정** | `0` ~ `3` | 후면 유리/뒷판 파손 상태 (0: 무하자 / 1: 미세기스 / 2: 깨짐 / 3: 사용불가) |
| **측면파손** | `0` ~ `3` | 테두리/프레임 상태 (0: 무하자 / 1: 작은 찍힘·생활기스 / 2: 심한 찍힘 / 3: 휨·파손) |
| **박스여부** | `1` 또는 `0` | 원본 박스 유무 (1: 있음 / 0: 없음) |
| **사설수리여부** | `1` 또는 `0` | 사설 수리 이력 또는 알림 유무 (1: 있음 / 0: 없음·정품수리) |
| **비고** | `블랙 색상, 충전선 포함...` | 색상, 구성품, 직거래 조건 등 핵심 특이사항 요약 |
| **게시물번호** | `1x4p1k8ofvza` | 당근마켓 게시글 고유 식별자 |

## 🚀 사용 방법

### 방법 1. 원클릭 실행 (가장 추천! ⭐)
1. 프로젝트 폴더 내 **`실행.bat`** 파일을 더블 클릭합니다.
2. (최초 실행 1회) 터미널 안내에 따라 본인의 **Google Gemini API Key**를 붙여넣습니다. (자동 저장됨)
3. 당근마켓 상품 URL을 붙여넣고 Enter를 누릅니다.
4. 분석 완료 후 `daangn_items.csv` 파일에 한 줄씩 데이터가 쌓입니다.
5. 종료를 원하시면 **`c`**를 입력하고 Enter를 누르시면 됩니다.

---

### 방법 2. 개발자 수동 실행 (CLI)

```powershell
# 1. 가상환경 활성화 (PowerShell)
.\.venv\Scripts\Activate.ps1

# 2. 필수 라이브러리 설치
pip install -r requirements.txt

# 3. Playwright 브라우저 설치
playwright install chromium

# 4. 프로그램 실행
python daangn_scraper.py
```

> **단발성 단일 실행**:
> ```powershell
> python daangn_scraper.py <당근마켓_URL>
> ```
